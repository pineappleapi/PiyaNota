# Divisi A6 (route B') Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the divisi corpus to the frozen A6 mix, get its labels user-checked (G1b), and train and gate a full CRNN
fine-tune that reads same-stem chords (2nds, 7ths, triads, ledger members included).

**Architecture:** The generator change lives in `inject_divisi` (`training/phase1/build_corpus.py`); everything downstream
(render, cut, manifest, converter) is reused unchanged except a font exclusion and a trainer sampling flag. A new mix/gate
script checks the corpus before GPU time; a new eval script scores per-epoch checkpoints offline at head level, applies
the selection rule and the section 6 gates.

**Tech Stack:** Python 3, music21, Verovio, PyTorch, pytest; Kaggle GPU kernels.

**Spec:** `docs/decisions/piya-106-divisi-a6-design.md` (frozen as A6 in `docs/decisions/piya-106-divisi-arm-freeze.md`).

## Global Constraints

- Python: `D:/PiyaNota/.venv/Scripts/python.exe -I`; never modify the shared venv. Scratch in `$CLAUDE_JOB_DIR/tmp`.
- Never read `D:/PiyaNota/datasets/phase4_strips/`; `piyanota_dataset` is TEST-only; no A6 checkpoint on Phase 4.
- No commit without user review and approval; message `PIYA-106: <summary>` plus the session trailer.
- Code style: type hints, Google docstrings explaining why, named constants, no silent `except`.
- Phase 1, Phase 2 and train-1 divisi outputs must not change: the A5 equality check (no Phase 1/2 strip changed) holds.
- Frozen values (copy, do not re-derive):
  - Members 60% free diatonic, 40% copied. Dyads 2nd 12, 3rd 16, 4th 12, 5th 12, 6th 12, 7th 5 (minor only), 8ve 16 (%).
  - Triads 15% of chord columns. ≥ 30% of 2nds stems down.
  - Durations whole 12, half 20, dotted 15, quarter 33, beamed 20 (%). ≥ 12% of chord columns with a drawn accidental.
  - Members within voice range + 2 semitones (S C4-A5, A G3-D5, T C3-A4 sounding, B E2-E4), clipped to steps -5..13 (L1 = 0).
  - 25% of divisi strips chord-free; the rest 20-60% chord columns. Ties 8% only if G1b passes the tie case.
  - Gootville held out of chord training. Realised mix within ±3 pp of every target.
  - Training: 8 epochs, lr 3e-5, init Phase 2 seed k, CPM replay 0.5, divisi = 20% ±3 pp of synthetic strips per epoch,
    fresh draw each epoch, seeds 1 and 2.
- Conductor rules: free members use only accidentals already in force in the bar (key signature + accidentals sounding
  in that bar, any voice), natural minor by default; reject aug 2nd/4th, dim 5th/7th, aug unison, chromatic 2nd on one
  stem; span ≤ 8ve; ≤ 3 notes per stem; member crosses the adjacent voice's sounding note in ≤ 10% of chord columns.

## Review Focus

1. A piece with no chord-capable note in a chosen strip (all tied/grace/tuplet): the strip stays plain and is counted, never
   loops or raises. Test in Task 3.
2. A free member whose only legal spelling needs an accidental not in force: re-drawn, then skipped with a logged
   shortfall after `MAX_REDRAWS`; never an invented accidental. Test in Task 2.
3. Mid-piece constructed key change: free members after it follow the new key. Test in Task 2.
4. Two strips of one voice-system in different fonts: the chord-free decision is per (piece, voice, system), so all fonts
   of that strip agree. Test in Task 3.
5. Eval on a strip where the decoder emits an untrained step (-6, 14..16): counted as hallucination, not dropped by the
   aligner. Test in Task 7.
