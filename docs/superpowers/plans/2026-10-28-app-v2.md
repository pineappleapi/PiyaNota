# App Version 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to carry out this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build every Module 2 change in `docs/tickets/module2-mobile-v2.md` (PIYA-201…211 V2.n) in the Flutter app, against the fake backend, with the HTTP side mapped to the backend contract in `docs/tickets/module3-backend.md` → "V2 notes (2026-10-28)" (B1–B5).

**Architecture:** No new layers. Each change goes into the screen, provider or API file that already owns that behaviour. There are two shared pieces. `Backoff` is one pure function used by Login and the reset code. `SplashGate` is one app-level observer that decides when the splash plays. The backend endpoints (B1, B3, B4, B5) do not exist yet. The app gets the HTTP error mapping for each one, and `FakeAuthApi` / `FakeScoreLibraryApi` act out the same behaviour so every AC can be tested now.

**Tech stack:** Flutter (Android), Riverpod, dio, shared_preferences, flutter_secure_storage, just_audio, camera. Tests use `flutter_test` with the existing fakes under `test/*/…_fakes.dart`.

**Working dir:** `D:/PiyaNota/.claude/worktrees/app-v2/mobile/piyanota_application`, branch `feature/app-v2`.

## Review focus (for reviewers)

1. **Task 3, the splash on warm resume.** Check that it never plays after a picker, the camera, a permission dialog or Settings returns. Check that it keeps screen state, so it must be an overlay and not a route.
2. **Tasks 4 and 8, `Backoff`.** Look for off-by-one in "from the 1st wrong attempt" vs "after the 3rd". Confirm the server's `retryAfterSeconds` overrides the app's count. Confirm a network failure is not counted.
3. **Task 19, zoom plus the stacked scroll plus auto-follow.** This has the highest risk: the gestures can conflict.
4. **Task 22, the default mix.** Check the interplay with failed-voice fallback and with chips that stack with the Mixer.

/// Plays the splash over whatever is on screen on cold start and on
